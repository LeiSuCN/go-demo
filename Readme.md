# Go HTTP服务示例

这是一个使用Go语言编写的简单HTTP服务示例，包含一个炫酷的首页。

## 功能特点

- 使用Go标准库实现的HTTP服务
- 炫酷的响应式首页设计
- 现代化的UI效果，包括渐变背景、动画和交互效果

## 快速开始

### 前提条件

- 已安装Go语言环境（推荐Go 1.16+）

### 运行步骤

1. 克隆或下载本项目到本地
2. 进入项目目录
3. 运行以下命令启动服务：

```bash
go run main.go
```

4. 打开浏览器，访问 http://localhost:8080

## 项目结构

- `main.go`: 主程序文件，包含HTTP服务的实现
- `go.mod`: Go模块定义文件
- `.gitignore`: Git忽略文件配置

## 自定义修改

你可以修改 `main.go` 文件中的HTML模板来自定义首页内容和样式。
